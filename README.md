# Standoff Web 3D

Браузерный FPS на Three.js: LAN-мультиплеер для 2–10 игроков через WebSocket, раунды, команды, MP7 и два дробовика. Отдельно доступна игра 5×5 против ботов. Сервер написан на Python 3 без сторонних зависимостей.

## Быстрый запуск

Нужен только **Python 3** и браузер с WebGL.

```bash
python3 serve.py
```

Сервер слушает **0.0.0.0:8000**. На компьютере-хосте можно открыть **http://127.0.0.1:8000/**, на втором — **http://IP_ХОСТА:8000/**. Другой порт: `python3 serve.py 8080`. Остановка — **Ctrl+C**.

На Windows также можно запустить `python serve.py` (или `py serve.py`). Файл `serve.py` обслуживает папку проекта, даже если запущен из другого рабочего каталога.

> Three.js 0.160.0 загружается из CDN: при первом запуске нужно подключение к интернету. npm, сборщики и `pip install` не требуются.

## Игра с другом в локальной сети

1. Подключите оба компьютера к одной сети. На хосте запустите **именно** `python3 serve.py` (Windows: `py serve.py`). `python -m http.server` **не подходит** — он не поддерживает игровые WebSocket.
2. Найдите LAN-IP хоста: Linux — `hostname -I`, Windows — `ipconfig` (IPv4). Например, `192.168.1.25`.
3. Оба игрока открывают `http://192.168.1.25:8000/` (хост также может открыть `127.0.0.1:8000`), вводят **одинаковый код комнаты** (`public` по умолчанию) и разные ники, нажимают **«Играть по сети»**. Второй игрок попадает в другую команду. После подготовки начинается общий раунд.
4. **«Тренировка с ботами»** — отдельный одиночный режим, которому не требуется WebSocket.

Если браузер на втором ПК вообще не открывает страницу, разрешите входящие TCP-подключения к порту 8000 в брандмауэре хоста (Ubuntu/UFW: `sudo ufw allow 8000/tcp`; Windows: входящее правило для TCP 8000). Убедитесь, что компьютеры не в гостевом Wi-Fi с изоляцией клиентов. Если страница открылась, но второго игрока нет, посмотрите статус в левом верхнем углу и Network → WS в DevTools, убедитесь, что запускается `serve.py`.

**Важно:** это LAN-прототип для доверенных игроков. Сервер ведёт команды, здоровье, счёт и раунды, но не имеет аутентификации и полноценного античита; попадания и положение игроков поступают от клиентов. Сетевой режим — без ботов, офлайн-тренировка — с ботами. Не публикуйте сервер напрямую в интернет без усиления безопасности и настройки HTTPS/WSS.

## Структура

```text
standoff/
├── index.html              # Разметка меню и игрового HUD, подключение JS/CSS
├── assets/
│   └── css/
│       └── style.css       # Стили интерфейса
├── src/
│   ├── core/state.js       # CONFIG, WEAPONS и состояние игры
│   ├── network/multiplayer.js # подключение и синхронизация игроков
│   ├── world/scene.js      # Three.js, карты и столкновения
│   ├── entities/
│   │   ├── actors.js       # Модели людей и создание ботов/игрока
│   │   ├── movement.js     # Движение игрока и AI ботов
│   │   └── spectator.js    # Режим наблюдения
│   ├── input/controls.js   # Клавиатура, мышь, захват курсора
│   ├── weapons/models.js  # 3D-геометрия MP7, дробовиков и деталей
│   ├── weapons/weapons.js  # Модели оружия, стрельба, урон, перезарядка
│   ├── game/
│   │   ├── rounds.js      # Логика раундов
│   │   └── main.js        # Главный цикл и запуск игры
│   └── ui/
│       ├── menus.js       # Выбор и покупка оружия
│       └── hud.js         # Таблица, сообщения, таймер и HUD
├── server/multiplayer.py   # Сервер WebSocket и матчей
├── tests/                  # Тест двух подключённых игроков
├── serve.py                # LAN HTTP + WebSocket (stdlib Python)
└── QWEN.md                 # Правила для Qwen
```

## Как изменять и отлаживать

1. Запусти `python3 serve.py`, открой адрес сервера.
2. В DevTools браузера открой **Console** для ошибок JS, **Sources** для breakpoints в отдельных файлах `src/`, **Network** для проверки загрузки ресурсов.
3. При изменении CSS/JS обнови страницу (Ctrl+R). Если браузер показывает старую версию, сделай принудительное обновление (Ctrl+Shift+R).

**Важно:** пока скрипты подключаются как обычные `<script src="…"></script>`, а не ES modules. Они используют общие глобальные переменные и функции; порядок загрузки в `index.html` важен. Если добавляешь новый файл, подключи его **до `src/game/main.js`**. Для полноценного перехода на `import/export` потребуется отдельный рефакторинг.

`index.html` — единственная актуальная точка входа. Предыдущая монолитная версия `станок 0.5.html` сохранена в истории Git.

## Управление

WASD — ходьба; мышь — обзор; ЛКМ — стрельба; R — перезарядка; Shift — бег; пробел — прыжок; B — магазин во время подготовки; 1–7 — выбор оружия; E — прицел AWM; Q — смена наблюдаемого союзника после смерти.

## Ограничения

Браузерный LAN-прототип. Для проверки: `python3 -m unittest discover -s tests -v`, `python3 -m compileall -q serve.py server tests`; JavaScript: `find src -name '*.js' -exec node --check {} \\;`. Проверяйте также на двух реальных компьютерах.
