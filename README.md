# Standoff Web 3D

Небольшой браузерный 3D-шутер: игрок и боты, команды 5×5, две карты, раунды, выбор оружия и режим наблюдения после смерти. Работает полностью в браузере; отдельный backend и база данных не нужны.

## Быстрый запуск

Нужен только **Python 3** и браузер с WebGL.

```bash
python3 serve.py
```

Открой **http://127.0.0.1:8000/**. Для другого порта: `python3 serve.py 8080`. Остановка сервера — **Ctrl+C**.

На Windows также можно запустить `python serve.py` (или `py serve.py`). Файл `serve.py` обслуживает папку проекта, даже если запущен из другого рабочего каталога.

> Three.js 0.160.0 загружается из CDN: при первом запуске нужно подключение к интернету. npm, сборщики и `pip install` не требуются.

## Как изменять и отлаживать

1. Запусти `python3 serve.py`, открой адрес сервера.
2. В DevTools браузера открой **Console** для ошибок JS, **Sources** для breakpoints в отдельных файлах `src/`, **Network** для проверки загрузки ресурсов.
3. При изменении CSS/JS обнови страницу (Ctrl+R). Если браузер показывает старую версию, сделай принудительное обновление (Ctrl+Shift+R).

**Важно:** пока скрипты подключаются как обычные `<script src="…"></script>`, а не ES modules. Они используют общие глобальные переменные и функции; порядок загрузки в `index.html` важен. Если добавляешь новый файл, подключи его **до `src/game/main.js`**. Для полноценного перехода на `import/export` потребуется отдельный рефакторинг.

`index.html` — единственная актуальная точка входа. Предыдущая монолитная версия `станок 0.5.html` сохранена в истории Git.

## Управление

WASD — ходьба; мышь — обзор; ЛКМ — стрельба; R — перезарядка; Shift — бег; пробел — прыжок; B — магазин во время подготовки; 1–4 — выбор оружия; E — прицел AWM; Q — смена наблюдаемого союзника после смерти.

## Ограничения

Это браузерный прототип с локальными ботами, **не сетевой мультиплеер**. Автотесты пока не добавлены; после изменения игровой логики проверь запуск, управление, карты, оружие и переход между раундами вручную.
