# Standoff Web 3D — инструкция для Qwen

## Что это за проект
- Репозиторий: **swrobotcompany-dev/standoff**; основная ветка — **main**.
- Браузерный прототип 3D FPS 5×5 (игрок + боты). Frontend на HTML, CSS, JavaScript и Three.js 0.160.0 (CDN).
- Без Node.js, npm, сборщика, backend, БД и сетевого мультиплеера. Локальный запуск: `python3 serve.py` → `http://127.0.0.1:8000/`.
- `README.md` — подробная структура и инструкции по запуску.

## Правила работы с проектом
1. **Точка входа — `index.html`**, не старый `станок 0.5.html` (он удалён из текущей ветки; доступен в истории Git).
2. Это **обычные скрипты, не ES-модули**: общий глобальный scope; порядок тегов `<script>` в конце `index.html` имеет значение. `src/core/state.js` загружается до остальных, а `src/game/main.js` — последним. Не добавляй `type="module"` или `import/export` без полноценного согласованного рефакторинга.
3. Меняй только относящиеся к задаче файлы. Не дублируй логику в HTML и не возвращай монолитный файл.
4. Перед сдачей проверь JS-синтаксис изменённых файлов, загрузку скриптов и CSS, запуск `python3 serve.py`, старт игры; по возможности проверь движение, стрельбу и переход между раундами. Не сообщай о тестах, которые фактически не запускал.
5. Не переписывай всё приложение, не внедряй npm/Vite/библиотеки без запроса пользователя. Не меняй CDN Three.js без проверки совместимости.

## GitHub и Pull Requests
- **Если пользователь прямо просит «в main сразу» — коммить изменения напрямую в main.** Иначе: новая ветка от актуальной `main` → изменения → PR в `main`.
- Для PR используй отдельную ветку `qwen/<краткая-задача>`. После создания PR дай реальную ссылку, не считай `push` или `commit` готовым PR.
- Пользуйся GitHub-подключением Qwen, если оно есть. **Никогда не проси у пользователя PAT/API token, GITHUB_TOKEN, GH_TOKEN, SSH private key, пароль, cookie и иные секреты. Не предлагай создавать токены или копировать их в чат.**
- Не приписывай ошибки веток или конфликтов проблемам с токеном. Если не удаётся отправить изменения, укажи точную ошибку GitHub и кратко скажи, что не получилось.
- Если не работает встроенное подключение GitHub, предложи проверить доступ приложения к репозиторию в настройках Qwen — **без передачи токенов**.
- Не делай force-push и не удаляй другие ветки/PR без явной просьбы пользователя.
